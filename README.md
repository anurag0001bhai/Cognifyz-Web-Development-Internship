## 📚 Levels Completed

- Basic form
- Navigation menu
- JavaScript color-changing button
- Time-based greeting
- Addition calculator

### Level 2 – Intermediate Web Development
- Responsive card using front-end framework
- Responsive grid layout
- CSS media queries

4. For the complete project, open the main `index.html`.
